# Explorable research presentations

Use this reference when the user requests an explorable presentation, progressive
reveals, an interactive mechanism explanation, or a teaching sequence. Keep the
paper's findings and the requested format, authorial voice, and existing design.

## Explain one mechanism at a time

Start from a concrete economic situation. Identify the actors, choices, relevant
constraint, and outcome before showing an abstract model or empirical contrast.
Use a running example only when it helps the audience follow the actual argument.

Let each reveal answer one question: what changed, which comparison identifies
the effect, or which mechanism produces the prediction. An audience prediction
before the reveal is useful when the answer teaches something; ordinary result
slides can state their supported finding directly.

Keep axis scales, units, samples, reference groups, legends, and uncertainty
consistent across the reveals. Maintain a single source for repeated numbers.
Record the paper page/table/column or analysis output behind each evidence frame.
Label stylized examples and simulations at the point of display.

## Match the requested format

- **PowerPoint:** use editable objects and readable charts. Consecutive reveal
  slides or supported builds can show the steps; preserve their final state in
  the handout. Reuse the available presentation tools.
- **Beamer/PDF:** use supported overlays or successive frames, with a final
  complete view for the handout. Reuse the project's compiler and theme.
- **Interactive web deck:** use live controls only when changing an input helps
  explain the model or evidence. Keep the evidence inputs and illustrative
  parameters distinct, and provide a readable static view.

Keep important empirical qualifications with the claim. Move optional derivations,
additional specifications, and question-specific detail to accessible backup
slides. Speaker notes explain each reveal and its transition.

## Verify completion

Inspect the rendered sequence and its static handout. Confirm that every stage
is legible, labels and data remain aligned, evidence is traceable, and the final
view supports the complete argument. The editable output follows the suite's
Office identity rules when the format is PPTX.

Guidance adapted from Claes Bäckman's `explorable-deck`, `explorable-beamer`, and
`explorable-pptx`; see [source attribution](../../shared-references/business-source-attribution.md).
