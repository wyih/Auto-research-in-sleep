# Barrios Skills 与 Business Research Suite：比较与吸收

审阅日期：2026-09-30。来源为本地克隆的 [Barrios88/barrios-skills](https://github.com/Barrios88/barrios-skills/tree/d50afc62f4c67535a1949d029dfa0462feb906fd)，提交 `d50afc62f4c67535a1949d029dfa0462feb906fd`。筛查了四个核心目录的 47 个技能入口，深入阅读与商科研究有关的数据、计量、文本、写作、预审和展示模块及相关参考文件、代码。README 的“46 core skills”与该提交实际文件数有差异，本比较按文件内容判断。

## 判断

你的 Suite 在完整研究链条、全文到方法证据、可行性校准、数据落地、结论与证据对应、中文数据获取，以及代码解释和独立核验方面已有更完整的安排。Barrios 值得吸收的优势集中在特定任务的操作细节：公开数据的身份与时点、金融文本测量、计量方法对应的诊断、经济量级表达，以及论文如何转成听众能理解的报告。

这次增加三个独立技能，并将其余有用内容接入已有设计、分析、写作模块。更新后的商科安装组为 28 个技能、13 个共享参考文件；新参考按任务读取。

## 吸收时的实质调整

计量指导采用研究问题对应的 estimand、比较组和推断方法。分期处理需要明确 cohort 和事件时间支持；IV 诊断需匹配异方差／聚类结构与弱工具推断；RD 保留阈值附近的局部解释。新增参考也区分政策动态 DiD 与金融市场异常收益事件研究。

文本模块吸收 FinBERT 与词典评分的思路，并把构念验证作为解释评分的依据。FinBERT 的英文金融极性标签、中文财报的语言适配、长文分段、缺失文本与零分、调参与验证样本分离，都会影响指标能支持的结论。

展示模块吸收来源到幻灯片的数值定位、保留关键回归列、讲稿计时和讨论人具体修改建议。常规作者报告沿用论文的主要发现与贡献；讨论人意见根据用户选择的角色呈现。

写作继续使用已有作者风格与 confident-prose 约束。吸收经济量级和方法说明的有效内容，保留原有否定、条件、比较方向、引文、零结果和混合结果。

## 当前未移入的内容

- `econ-lit-search` 的公开版本缺少可用的语料服务配置：脚本把 `${MEILI_HOST:-...}` 留在 Python URL 字符串中，README 所述可直接访问的约 5.1 万篇语料没有在该克隆中形成可运行入口。因此没有把它接成现成检索源。
- WRDS／SEC／OpenEcon MCP 服务与技能是不同组件。这次吸收技能指导，使用已有连接器或官方 API；未安装新的外部服务。
- 上游 `r-econometrics` 末尾包含发送本地调试日志的内嵌脚本；它与计量任务无关，未纳入参考文件。
- PyMC、Dask、Polars、地理数据、网站／视频传播和基金申请等能力，需由具体研究任务证明其用途。这次改动聚焦会直接改善当前商科研究套件的内容。

## 落地与验证范围

修改位于共享技能源和 Codex 覆盖文件，通过现有生成器同步到 Codex 与 Kimi 包，并更新选择性安装目录、使用指南和技能清单。来源及 MIT 声明保存在 [共享署名文件](../skills/shared-references/business-source-attribution.md)，随安装组分发。

本次验证覆盖技能格式、引用解析、包一致性、目录完整性和实际安装后的技能发现。公开数据获取、文本模型评分和幻灯片生成将在对应研究任务中执行；这次没有将这些外部执行描述为已完成的数据或分析结果。

核验结果：47 项既有测试通过；主线、Codex、Kimi 共 84 个商科技能入口通过格式检查；新增资源的 36 个 Markdown 文件完成本地链接检查，未发现悬空引用；当前项目的 28 个商科技能安装链接与清单一致。
